# database/datafiles — what every file is, what it is for, how it is made

`database/datafiles/` is git-ignored as a whole. Only 31 hand-curated experiment
definitions under it are force-tracked (holdout and exclusion id lists, the
banned-typo keys, the ICSD request list). Everything else is a raw download or a
derived artifact regenerated by the pipelines in `database/pipelines/`.

Conventions used below. An **index** is a DataFrame pickle (+ csv twin) with the
columns `id, value, graph_path, label, tc` that the loaders consume: `id` is the
graph file name (`<formula>-MP-<parent id>[-synth_doped].cif`), `value` the training
target, `label` 1 for every superconductor-database row, `tc` in kelvin (0 = measured
non-superconductor). A **descriptor table** is `{names, table, failed}` with 41
composition/structure descriptors per id (`models/head/descriptors.py`), consumed by
the T_c head beside the encoder latents. A **pack** is the columnar training format
written by `main.py pack-dataset` (24 files: node/edge/poly arrays, targets, header).
A **graph** is one compact JSON per material from `database/database_main.py`
(nodes, bonding and polyhedral edges, angle triplets, dihedrals, optional baked targets).
A **holdout list** is a one-column `id` csv forced into the test fold by `holdout_ids_csv`.

## MP — the superconductor corpus (3DSC base, expansions, negatives, screen)

### Raw inputs
| file | what it is |
|---|---|
| `3DSC_MP.csv` | 3DSC's metadata table (Sommer et al. 2023): one row per MP-matched SuperCon entry — `formula_sc`, matched CIF, `tc`, `sc_class` (family), doping/similarity fields. Source of the family labels the head reports by. |
| `cifs/` | 3DSC's MP-matched CIFs, one per row of `id_prop.csv` (10,904 files incl. synth-doped variants). |
| `id_prop.csv` | the `build-db` source list: `<cif file>,<tc>`, one line per 3DSC row (5,772). `id_prop.pickle`, `id_prop_basic.*` are the same rows with the parsed structure dict, from the original CGCNN-era loader. |
| `SuperCon_Stanev2018.csv` | the 16,414-row SuperCon export (`name, Tc`) used to find every composition 3DSC did not match. |
| `ICSD_Parent_Cifs/` | 30 hand-downloaded ICSD refinements used as tier-0 parents (oxygen-loaded 123s, Bi-2212/2213, La-214, the Sr14Cu24O41 ladder approximant, ...). Licensed; not scripted. |
| `atom_init.json` / `.pickle` | per-element input feature table for the graph loaders (`main.py atom-init`). |

### Family metadata
`3DSC_MP_v8/v9/v10/v11.csv` — `3DSC_MP.csv` extended with one row per expansion / negatives id so
`HeadData.load_family_metadata` assigns every row a family (Cuprate, Ferrite, Oxide, ...) instead of "Other". Regenerated by the merge steps.

### Descriptor tables (41 dims, keyed by id)
`descriptors_doped.pickle` (V45 base), `descriptors_doped_oxifix`, `descriptors_v4_plus_nickelates`, `descriptors_v4m`, `descriptors_v4m_plus`, `descriptors_magnetic_rows`, `descriptors_v5_nemad`, `descriptors_v5_icsd`, `descriptors_v5_expanded`, `descriptors_v6_expanded`, `descriptors_v6m`, `descriptors_v7_supercon`, `descriptors_v8_supercon`, `descriptors_v9_cuneg_only` (571) and `descriptors_v9_cuneg` (merged), `descriptors_v10`, `descriptors_v11_feox_only`, `descriptors_v11`, `descriptors_v11c`, `descriptors_screen_mp` (93,561 MP screen rows). Each matches the index of the same name row-for-row; all were re-assembled after the 2026-09-17 graph rebuild.

### Graphs (compact JSON per material)
| directory | what |
|---|---|
| `graphs_v4_doped_v45/` | the 5,773 base rows (schema v4.5, CF/BVS baked). |
| `graphs_v4_v7_supercon/`, `graphs_v4_v9_cuneg/`, `graphs_v4_v11_feox/` | expansion and the two negatives tiers (rebuilt 2026-09-17 with the polyhedral-sharing block populated). |
| `graphs_v5_nemad_v45/`, `graphs_v5_icsd_v45/` | the NEMAD / ICSD expansion rows at v4.5. |
| `graphs_v4/` | 89,231 graphs = every MP material with a local v45-schema graph (phonon corpus + DOS rebuild, deduped) — the discovery-screen input. |
| `dos_rebuild/` | the DOS-corpus working set (62k undoped MP graphs with ±1 eV DOS attached, `dos_all_index.pickle`, `cifs/`, `dos_new_source.csv`) — see `database/pipelines/dos_rebuild/README.md`. |
| `disorder_corpus/` | 53k ordered mixed-element MP structures merged to fractional occupancy (`graphs_v45/`, `source.csv`, `cifs/`) — the doping-aware pretraining member. |
| `magnetic_rebuild/` | graphs for the 2026-07 magnetic-negatives rows (V4M/V6M). |

### CIF sets (inputs to `build-db` for each expansion)
`cifs_v5_nemad/`, `cifs_v5_icsd/`, `cifs_v7_supercon/`, `cifs_v9_cuneg/`, `cifs_v11_feox/` — one synthetically doped CIF per expansion row, written by the matchers.

### Packs
`SC_pack_doped_v45/` (base), `SC_pack_nick_v45/` (with nickelates), `SC_pack_v6_v45/`, `disorder_pack_v45/`, `dos_pack_ef1_v45/` (the DOS member, 128-bin ±1 eV DOS) — the v4.5 packs the pretraining rungs read (mirrored to cluster scratch). `SC_pack_doped`, `SC_pack_doped_cf`, `SC_pack_doped_v44` are the earlier-schema packs kept because ~100 historical head configs reference them.

### Holdout / exclusion lists (experiment definitions; tracked)
| file(s) | defines |
|---|---|
| `la_series_both_holdout_ids*.csv`, `lsco_*`, `lcco_ce_series_*` | the La₂₋ₓ(Sr,Ba,Ce)ₓCuO₄ doping-dome holdout (Sr and Ce series; `_v9/_v10/_v11/_v11c` = the same series filtered to each index, `lsco_holdout_srce_v6`, `lsco_trainforce_v6` = the V6 era source/train-force variants). |
| `nickelate_holdout_ids*.csv` | the 52-row nickelate zero-shot holdout (d9 infinite-layer, RP/214, Ni pnictide-oxides), per index; `_v4m/_v6m` include the magnetic Ni oxides. |
| `holdout_fam_{bi,hg,yba,tprime}_ids.csv` | element-set family holdouts (Bi, Hg, YBa, T′ cuprates). |
| `holdout_struct_*_ids.csv`, `exclude_struct_*_ids.csv` | structure-type holdouts via cation-framework matching (`scripts/structure_holdout.py`) and the rows excluded from training for them (RE-123 analogs, suspects); `rebco123` = all 123-framework rows. |
| `holdout_matthias_{all,dome1,dome2,more,nbzr,tiv}_ids*.csv` | the valence-electron (Matthias) dome holdouts: all 304 alloy systems, the first/second-hump families, and the single series Mo-Re, Nb-Zr, Ti-V. |
| `leakfree_split.csv` | the parent-grouped train/val/test assignment used for the leak-free from-scratch CGCNN comparison. |
| `tc_label_review.csv`, `tc_label_qa_exclusions.csv` | 2026-07 label QA: 3DSC vs NEMAD T_c disagreements and the 4 rows excluded. |

### Curation working files
`ICSD_parent_scan.csv` (what each ICSD CIF contains), `ICSD_pull_list.csv`, `ICSD_pull_targets_detail.csv` (2026-08 ICSD request), `nemad_doping_failures.csv`, `nemad_o_interstitial_targets.csv` (why NEMAD candidates failed to dope; the O-interstitial subset).

### Discovery screen
`screen_mp_index.pickle` (93,561 local MP graphs), `screen_mp_metadata.pickle` (72,887 MP summary rows: e_hull, band gap, theoretical flag, ...), `descriptors_screen_mp.pickle`, `pred_cache_screen_{47,51}.pt` (cached per-atom predicted-feature tensors for the α²F-head Eliashberg readout), `pred_cache/` (head-side caches). Built by `database/pipelines/mp/build_mp_screen.py`; results in `docs/data_curation/mp_screen_v*.csv`.

- V11c was built inline (its ids are the index itself).
- Two names to watch: `SC_MP_V9_cuneg` is the MERGED V9; the negatives-only tier is `SC_MP_V9_cuneg_only` (they collided until 2026-09-18).
