This project is a machine learning model to predict superconductors.

First Step

The first part of this project will simply be predicting if a compound will super conduct. This will be mostly to set up the database and determine what features are necessary to accurately predict superconductors. This will both determine the required inputs (i.e. is compound enough, or should input vectors include lattice information, band structure, etc?) and what will be used for training data.

Input

To start, just compound information will be used. The input will be a 1D vector of arbitrary length with the elements in the compound and their amounts. The input will then be formatted into a 2D tensor with additional element information from the database.
